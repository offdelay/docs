# Modules

Offdelay is organized into modules. Each module bundles a set of related
capabilities.

- [Energy](energy/index.md) — power monitoring and management
- [Lighting](lighting/index.md) — light control and scenes
- [Heating and cooling](heating-cooling/index.md) — heating and cooling control
- [Screens](screens/index.md) — screen and shading control
- [Alarm systems](alarm-systems/index.md) — alarm system integration
