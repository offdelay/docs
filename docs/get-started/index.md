# Get started

The site has three main sections in the header: **Get started**, **Setup**, and **Modules**.

- **Get started** covers the basics of navigating Home Assistant in an existing, working installation.
- **Setup** guides you through configuring a basic Home Assistant installation, including its standard home assistant and Offdelay components.
- **Modules** explains the integrated concepts supported by Offdelay, such as lighting, energy, heating and cooling, screens, and alarm systems.

Start here to learn your way around Home Assistant before setting up your installation or exploring Offdelay modules.
