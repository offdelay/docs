# Integrations

Integrations connect Home Assistant to devices, services, and other software. Use the tab that matches the integration you want to install.

=== "Official Home Assistant"

    Add integrations included with Home Assistant from its integration directory:

    1. Go to **Settings > Devices & services**.
    2. Select **Add integration** (the **+** button).
    3. Search for the integration and follow its setup steps.

=== "Marketplace"

    Install the integration from **Marketplace**, then add it to Home Assistant:

    1. Go to **Settings > Marketplace**.
    2. Search for the integration and select **Install**.
    3. Go to **Settings > Devices & services**.
    4. Select **Add integration** (the **+** button), search for the integration, and follow its setup steps.

=== "Offdelay supported"

    Offdelay supports several integrations for use with the Offdelay setup.
