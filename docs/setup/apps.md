# Apps

Apps add services and tools to your Home Assistant installation. Use the tab that matches the app you want to install.

=== "Official Home Assistant"

    Install apps available in your Home Assistant app catalog:

    1. Go to **Settings > Apps**.
    2. Find the app and select **Install**.

=== "Marketplace"

    Add the app's repository to Marketplace, then install the app:

    1. Go to **Settings > Marketplace**.
    2. Open the three-dot menu in the upper corner and select **Repositories**.
    3. Add the repository URL published by the app's maintainer.
    4. Find the app in Marketplace and select **Install**.

=== "Offdelay supported"

    Offdelay supports several apps for use with the Offdelay setup.
