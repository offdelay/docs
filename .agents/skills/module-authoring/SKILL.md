# Module authoring

Use this layout for module index pages:

- Start with the module name as the H1 and a short introduction.
- Add top-level sections for implemented control methods, such as `## Physical Control`, `## Dashboard Control`, and `## Voice Control`. Include only methods the module supports and adapt the sections when other methods fit better. Add tabs within a method when it has multiple implementations or options.
- Add a `## Configuration` section with `### Add device`, `### Add visualisation`, and `### Add automation` subsections. Include only relevant, implemented guidance.

Keep text concise. Link to relevant setup pages and follow the `docs-authoring` and `image-naming` skills when applicable.
