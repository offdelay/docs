# Docs authoring

How to write documentation for Offdelay.

## Structure

- Use a single `#` H1 per page, matching the page title.
- Use ATX headings, fenced code blocks with a language tag, and relative
  links to `.md` files.

## Style

- Write short, direct sentences in the imperative where possible.
- Put the action first; keep paragraphs focused on one idea.
- Use front matter sparingly: `title`, `description`, and `icon`.

## Formatting

- Use the recommended VS Code extensions to format Markdown, YAML, and JSON.
- Prettier formats Markdown and other supported files; do not format
  `zensical.toml` with Prettier.
