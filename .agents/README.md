# Agent skills

This directory contains modular skills and guidelines for AI coding agents.
It is symlinked to `.claude` so Claude Code (and compatible agents) pick it
up automatically.

## Skills

- [`zensical`](skills/zensical/SKILL.md) — how to build, serve, and configure
  this Zensical site.
- [`docs-authoring`](skills/docs-authoring/SKILL.md) — writing and style
  guidelines for Offdelay documentation.

## Conventions

- One folder per skill, each containing a `SKILL.md`.
- Keep skills focused, short, and actionable.
- Prefer concrete commands and file paths over prose.
